# LLM Baseline Prediction (Original Titles)

This directory contains baseline experiments for LLM-based recommendation using **original item titles** from metadata (not condensed titles generated by LLM).

## Purpose

Provides a baseline comparison to evaluate the effectiveness of condensed titles vs original full titles for LLM recommendation tasks.

## Key Results

| Metric | Original Titles | Condensed Titles | Improvement |
|--------|-----------------|------------------|-------------|
| HR@1   | 5.13%           | 9.26%            | +80.5%      |
| HR@5   | 6.87%           | 11.41%           | +66.1%      |
| HR@10  | 7.65%           | 12.18%           | +59.2%      |
| HR@20  | 8.49%           | 12.91%           | +52.1%      |

**Conclusion**: Condensed titles (2-4 words) significantly outperform original full titles.

## Method

### 1. Initial Approach (`prepare_and_evaluate_baseline.py`)

- Uses original full titles from `meta_All_Beauty.jsonl`
- Generates prediction via LLM inference
- Matches predictions using string similarity (SequenceMatcher)
- **Problem**: Extremely slow (~25 hours estimated)

### 2. Optimized Approach (`prepare_and_evaluate_baseline_optimized.py`)

Key optimizations:
- **Batch inference**: Process 16 samples at once
- **Pre-computed embeddings**: Cache item title embeddings using model's hidden states
- **Vector similarity**: Use GPU-based cosine similarity instead of CPU string matching
- **Execution time**: ~5 minutes (vs 25+ hours)

## Usage

```bash
# Run optimized baseline evaluation
python prepare_and_evaluate_baseline_optimized.py
```

## Technical Details

### Embedding Computation

Title embeddings are computed using the model's last hidden states with mean pooling:

```python
# Mean pooling over non-padding tokens
hidden_states = model.model(**inputs).last_hidden_state
attention_mask = inputs['attention_mask'].unsqueeze(-1)
masked_hidden = hidden_states * attention_mask
embedding = masked_hidden.sum(dim=1) / attention_mask.sum(dim=1)
```

### Similarity Matching

Cosine similarity between predicted embedding and all item embeddings:

```python
predicted_norm = F.normalize(predicted_embedding.unsqueeze(0), dim=1)
item_norms = F.normalize(item_embeddings, dim=1)
similarities = torch.mm(predicted_norm, item_norms.T)
```

## Notes

1. **Device Handling**: Uses `.cuda()` directly instead of `device_map="auto"` to ensure all tensors are on the same GPU.

2. **Title Source**: Uses original titles from metadata (`meta_All_Beauty.jsonl`), not the condensed titles from `item_titles_unique.json`.

3. **Comparison**: This baseline should be compared against `LLM_Rec_Data_Preparation/evaluate_qwen.py` which uses condensed titles.
